# 02 Metatables and OOP Kata

Exercises demonstrating object-oriented programming patterns using Lua's metatables.

## Files

- `vector2d.lua`: Operator overloading (`__add`, `__mul`, `__tostring`, `__eq`).
- `class_inheritance.lua`: Single prototype inheritance and method overrides.

## Run

```bash
lua vector2d.lua
lua class_inheritance.lua
```
