# 01 Basics Kata

Exercises covering basic Lua concepts: tables, loops, string patterns, and closures.

## Files

- `basic_types.lua`: Numbers, strings, truthiness, and 1-based indexing.
- `closure_memo.lua`: Lexical scoping, counters, and caching function results.
- `pattern_matching.lua`: Pattern matching using `string.match` and `string.gmatch`.

## Run

```bash
lua basic_types.lua
lua closure_memo.lua
lua pattern_matching.lua
```
